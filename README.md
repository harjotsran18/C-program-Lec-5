# C Program - Lec 5

Semester II - C Programming practice exercises and lecture examples.

## Topics Covered
- Storage Classes (`auto`, `static`)
- Constants and Preprocessor Directives (`const` qualifier, `#define`)
- Functions with `void` return type
- Variable scopes and persistence across function calls

## Programs

- **`auto.c`**: Demonstrates the `auto` storage class and local variable lifecycle alongside a `static` counter variable.
- **`const.c`**: Demonstrates constant values using `#define` preprocessor macros and the `const` keyword, manipulated with a persistent static variable.
- **`void.c`**: Demonstrates a basic function with `void` return type utilizing a `static` variable to preserve state across function calls.

## Additional Materials

- **`Variables and Constants.docx`**: Lecture notes covering variable declarations, constants, and storage classes.

## How to Compile and Run

Using MinGW / GCC:

```bash
gcc filename.c -o filename.exe
./filename.exe
```
